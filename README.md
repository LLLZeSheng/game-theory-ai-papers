## 收录范围

博弈论需要进入论文的问题定义、算法设计或核心评测，而不是只在背景中出现。当前覆盖六条主线：

1. LLM 智能体的策略推理、协作、谈判与安全；
2. 多智能体强化学习、Markov games、mean-field games 与博弈求解；
3. 机制设计、拍卖、市场与激励；
4. 社会选择、投票、匹配与公平分配；
5. 战略机器学习、信息设计与对手建模；
6. 合作博弈、Shapley value、数据估值与可解释性。

不收录普通多智能体应用、仅以电子游戏为数据来源的视觉论文、GAN/对抗样本论文，以及与博弈论无关的 deep equilibrium 或物理学 mean-field 工作。

会议包括 NeurIPS、ICLR、ICML、AAAI、AAMAS、IJCAI，并持续补充 UAI、COLT、ACM EC 等同级别会议。期刊优先覆盖 Nature Machine Intelligence、TPAMI、JMLR、TMLR、Artificial Intelligence、JAIR 等。条目统一链接到官方 proceedings、出版社页面或 arXiv；预印本不会伪装成正式发表论文。

## 标记说明

- `LLM agents`：语言模型智能体与策略行为
- `equilibrium / learning in games`：均衡计算、遗憾最小化与学习动力学
- `MARL / MFG`：多智能体强化学习与 mean-field games
- `mechanism / market`：机制设计、拍卖、定价与市场
- `social choice`：投票、匹配、公平分配与联盟形成
- `cooperative games`：Shapley value、合作博弈与数据估值
- `strategic ML`：战略分类、数据操纵、信息设计与对手建模
